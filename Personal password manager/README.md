# Password Manager

A simple password manager built with Python and Tkinter as part of my Python learning journey.

## Current Version

This version focuses primarily on practicing GUI development with Tkinter.

### Features

* Graphical user interface built with Tkinter
* Website, email/username, and password input fields
* Password generation
* Input validation
* Error messages using Tkinter message boxes
* Basic layout management using `grid()`

## What I Practiced

This project helped me practice:

* Creating and configuring Tkinter widgets
* Using `Entry`, `Label`, and `Button` widgets
* Positioning widgets with `grid()`
* Retrieving user input with `.get()`
* Handling button commands
* Using `messagebox`
* Working with functions
* Basic input validation

## Planned Improvements

The next major version will introduce JSON for storing and retrieving password data.

Planned improvements include:

* Saving credentials to a JSON file
* Searching for saved credentials
* Retrieving stored passwords
* Handling missing websites
* Improving the overall data-management structure
